# AI Beauty App - 膚色檢測功能

## 功能概述

本應用實現了完整的膚色檢測功能，包含兩種檢測方式：

### 1. 相機掃描
- 使用瀏覽器相機API獲取實時視頻
- 拍攝照片後進行圖像分析
- 自動檢測膚色並分類

### 2. 手動輸入
- 用戶可手動選擇膚色類型
- 提供預設的膚色參數

## 技術實現

### 膚色檢測算法

#### 圖像分析流程：
1. **圖像採樣**: 從視頻幀中央區域採樣像素
2. **膚色過濾**: 使用YCbCr色彩空間過濾膚色像素
3. **顏色計算**: 計算平均RGB值
4. **膚色分類**: 基於亮度和暖度分類膚色

#### 膚色分類邏輯：
```javascript
const classifySkinTone = (r, g, b) => {
  const brightness = (r + g + b) / 3
  const warmth = r - b

  if (brightness > 200) {
    return warmth > 20 ? '暖白皮' : '冷白皮'
  } else if (brightness > 150) {
    if (warmth > 30) return '小麥皮'
    else if (warmth > 10) return '黃皮'
    else return '冷白皮'
  } else {
    return '古銅皮'
  }
}
```

### 產品推薦系統

基於檢測到的膚色類型，提供個性化產品推薦：

- **冷白皮**: 玫瑰色調粉底、藍色系遮瑕膏
- **暖白皮**: 暖橘色調粉底、黃色系遮瑕膏
- **黃皮**: 中性色調粉底、綠色系遮瑕膏
- **小麥皮**: 暖棕色調粉底、紫色系遮瑕膏
- **古銅皮**: 深色調粉底、橙色系遮瑕膏

## 使用方法

1. 訪問 `story1.php` 頁面
2. 選擇檢測方式：
   - **相機掃描**: 點擊"啟動相機"，允許權限，拍攝並分析
   - **手動輸入**: 從下拉選單選擇膚色類型，點擊"分析並推薦"
3. 查看膚色座標和產品推薦

## 技術特點

- **即時分析**: 相機掃描提供實時膚色檢測
- **精確分類**: 基於RGB值的科學分類算法
- **個性化推薦**: 針對不同膚色提供最適合產品
- **錯誤處理**: 完善的錯誤提示和資源清理
- **響應式設計**: 支持移動設備和桌面瀏覽器
